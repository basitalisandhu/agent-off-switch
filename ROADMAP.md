# Roadmap

This is what we are working on and what we would like help with, in plain order. It is a list of intentions, not promises: there are no dates, and the order changes when people show up or the evidence changes. Every item links an issue. Comment there to claim it or to argue for a different order, or vote in the [Roadmap discussion](https://github.com/basitalisandhu/agent-off-switch/discussions/16).

## Not planned

- Running any command it prints. `aos off` prints commands for a person to run; it will not run them.
- Network calls, stored credentials or usage reporting. It stays offline on saved read-only exports.

Want to add something? Open an issue describing the problem first, with what done looks like. The [CONTRIBUTING.md](CONTRIBUTING.md) file explains the rest.
